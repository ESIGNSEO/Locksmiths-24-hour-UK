# Technical Decisions & Project Constraints

## Technology Stack
- **Framework:** Next.js 16 (App Router) using Static Site Generation (SSG) for all pages.
- **Styling:** Tailwind CSS v4 using a premium custom HSL color palette (Dark Navy background `#0a1029`, Foreground `#fafafa`, Accent Yellow `#ffd900`).
- **Data Source:** `src/data/locations.ts` contains 1,847 compiled towns generated by `scripts/generate-locations.js`.

## SEO Content Variation Engine
- **Location:** `src/utils/seo-engine.ts`
- **Method:** Seeded deterministic spintax generator using the town name as the seed. Ensures distinct page copies across 1,847 locations while preventing React hydration mismatches.

## Project Constraints
- **Phone Number:** `07742 831011` linked directly on all pages (Tel and WhatsApp).
- **No Email Address:** Emails are strictly forbidden on the website.
- **Coverage:** Limited to England, Scotland, and Wales (excluding Northern Ireland).
- **Auto-Locksmith Limitations:** Explicitly states that car locksmith services are strictly limited to opening locked vehicles (no car key cutting, remote programming, or transponder configuration).
